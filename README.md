# 🚀 Get Hyped - Creative Agency Website

Welcome to the official repository of **Get Hyped**, a high-performance, visually stunning creative agency website built with the **MERN Stack** (specifically React, Tailwind CSS, and Framer Motion). This project features cutting-edge animations, professional routing, and a seamless user experience across all devices.

## ✨ Features

- **Dynamic Hero Section:** Engaging visuals with a high-impact "Get Hyped" call-to-action.
- **Interactive Card Stacks:** Smoothly animated expertise cards that grab attention.
- **Advanced Animations:** - Custom **Text Flip** & **Bottom-up Background Fill** hover effects in the Navbar and Footer.
  - Interactive **Video Hover Playback** (Videos play only when hovered and reset on leave).
  - Spinning dynamic badges for a premium feel.
- **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop with a mobile-first approach.
- **Smooth Navigation:** Integrated `ScrollToTop` functionality for a fluid multi-page experience.
- **Modern UI/UX:** Built with a clean, "Slanted" design aesthetic using custom Clip-Paths.
- **Toast Notifications:** Styled notifications for user interactions via `React-Toastify`.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Framer Motion
- **Icons:** React Icons (Fi, Fa)
- **Routing:** React Router DOM
- **Deployment:** Vercel (Configured for SPA routing)
- **Notifications:** React Toastify
